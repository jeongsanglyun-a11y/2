현재 만들어진 앱을 기반으로 아래 기능들을 수정 및 추가해줘.

중요:

* 현재 정상적으로 작동하는 기능은 유지한다.
* 앱을 처음부터 다시 만들지 않는다.
* 기존 데이터가 있다면 최대한 보존한다.
* 아래 요구사항을 기존 UI와 디자인에 자연스럽게 통합한다.
* 모바일 환경을 최우선으로 한다.
* 수정 후 기존 기능이 깨지지 않았는지 확인한다.

━━━━━━━━━━━━━━━━━━

1. 금액 빠른 추가/차감 버튼 수정
    ━━━━━━━━━━━━━━━━━━

현재 10,000원 / 30,000원 / 50,000원 / 100,000원 버튼이 있는데,
현재는 같은 버튼을 여러 번 눌러도 금액이 중복으로 추가되지 않는 문제가 있다.

이 기능을 “누적 입력 방식”으로 변경한다.

예:

+10,000원을 3번 누르면
→ +30,000원

+30,000원을 2번 누르면
→ +60,000원

+5,000원을 4번 누르면
→ +20,000원

처럼 같은 버튼을 여러 번 눌러도 계속 누적되어야 한다.

또한 저축뿐만 아니라 소비에서도 동일한 방식으로 사용할 수 있게 한다.

빠른 금액 버튼은 다음과 같이 구성한다.

+1,000원
+3,000원
+5,000원
+10,000원
+30,000원
+50,000원
+100,000원

버튼을 여러 번 누른 후 최종 금액을 한 번에 추가할 수 있어야 한다.

예:

+10,000
+10,000
+30,000
+5,000

→ 총 55,000원

“추가” 버튼을 누르면 55,000원이 하나의 거래로 기록된다.

또한 금액을 잘못 입력했을 때 사용할 수 있도록:

* 초기화
* 취소/되돌리기

기능도 제공한다.

가능하다면 빠른 버튼 영역에 현재 누적 입력 금액을 크게 표시한다.

예:
현재 입력 금액
₩55,000

━━━━━━━━━━━━━━━━━━
2. 저축 / 소비를 명확하게 분리
━━━━━━━━━━━━━━━━━━

현재 저축 기능만 존재하는 구조를 확장해서
“저축”과 “소비”를 각각 관리할 수 있도록 한다.

메인 구조:

저축
소비

또는

상단 탭:
[ 저축 ] [ 소비 ]

형태로 직관적으로 전환할 수 있게 한다.

저축 탭:

* 총 저축액
* 이번 달 저축액
* 저축 목표
* 최근 저축 내역
* 저축 범주별 통계

소비 탭:

* 총 소비액
* 이번 달 소비액
* 최근 소비 내역
* 소비 범주별 통계

━━━━━━━━━━━━━━━━━━
3. 저축 범주 시스템
━━━━━━━━━━━━━━━━━━

저축 거래를 범주별로 관리할 수 있어야 한다.

기본 저축 범주:

* 용돈
* 알바
* 선물
* 장학금
* 기타

하지만 사용자가 직접 범주를 추가할 수 있어야 한다.

예:

* 부모님 지원
* 중고거래
* 보너스
* 주식 수익
* 기타 개인 범주

기능:

* 범주 추가
* 범주 이름 수정
* 범주 삭제

범주별로 저축 금액을 집계한다.

예:

용돈 ₩500,000
알바 ₩300,000
부모님 지원 ₩200,000

각 범주가 전체 저축액에서 차지하는 비율도 표시한다.

━━━━━━━━━━━━━━━━━━
4. 소비 범주 시스템
━━━━━━━━━━━━━━━━━━

소비도 저축과 동일한 방식으로 범주화한다.

기본 소비 범주는 예를 들어:

* 식비
* 교통
* 쇼핑
* 여가
* 생활
* 교육
* 기타

사용자가 직접 소비 범주를 추가할 수 있어야 한다.

예:

* 자전거
* 게임
* 카페
* 여행
* 구독
* 전자기기

기능:

* 범주 추가
* 범주 이름 수정
* 범주 삭제

소비 범주별로:

* 소비 금액
* 전체 소비에서 차지하는 비율

을 계산해서 보여준다.

━━━━━━━━━━━━━━━━━━
5. 저축/소비 거래 기록
━━━━━━━━━━━━━━━━━━

저축과 소비 모두 하나의 거래 단위로 기록한다.

저축 거래:

* 금액
* 날짜
* 범주
* 메모
* 연결된 저축 목표(선택)

소비 거래:

* 금액
* 날짜
* 범주
* 메모

각 거래는:

* 수정
* 삭제

할 수 있어야 한다.

거래를 수정하거나 삭제하면 모든 통계와 목표 금액이 즉시 다시 계산되어야 한다.

━━━━━━━━━━━━━━━━━━
6. 저축 목표 시스템 개선
━━━━━━━━━━━━━━━━━━

저축 목표를 수정할 수 있어야 한다.

각 목표:

* 목표 이름
* 목표 금액
* 현재 저축액
* 남은 금액
* 달성률
* 원형 Progress Ring

목표를 여러 개 만들 수 있어야 한다.

예:

맥북 구매
목표 ₩2,000,000

카본 휠
목표 ₩1,500,000

여행
목표 ₩1,000,000

각 목표는 독립적으로 관리한다.

사용자가 목표를:

* 추가
* 수정
* 삭제

할 수 있어야 한다.

목표 수정 시:

* 목표 이름
* 목표 금액
    등을 변경할 수 있어야 한다.

저축 거래를 특정 목표에 연결하면 해당 목표의 현재 저축액과 달성률에 반영한다.

━━━━━━━━━━━━━━━━━━
7. 월별 캘린더
━━━━━━━━━━━━━━━━━━

새로운 핵심 기능으로 월별 캘린더를 추가한다.

한 달을 전체적으로 볼 수 있는 캘린더 UI를 만든다.

각 날짜에 해당 날짜의 저축/수입과 소비 금액을 표시한다.

색상 규칙:

저축/수입 → 초록색
소비 → 빨간색

예:

10월 4일
+₩20,000

10월 5일
-₩8,000

처럼 날짜 아래에 금액을 표시한다.

하루에 여러 거래가 있다면 해당 날짜의 합계를 표시한다.

예:

10월 6일
+₩50,000
-₩12,000

또는

수입/저축 +₩50,000
소비 -₩12,000

처럼 구분해서 표시한다.

캘린더에서 월을:

* 이전 달
* 다음 달

로 이동할 수 있어야 한다.

현재 월의 전체적인 돈의 흐름을 한눈에 파악할 수 있어야 한다.

━━━━━━━━━━━━━━━━━━
8. 월별 요약
━━━━━━━━━━━━━━━━━━

캘린더 상단 또는 하단에 해당 월의 요약 정보를 표시한다.

예:

10월

수입/저축
+₩850,000

소비
-₩320,000

순증가
+₩530,000

월별 데이터를 자동으로 계산한다.

━━━━━━━━━━━━━━━━━━
9. 데이터 계산 규칙
━━━━━━━━━━━━━━━━━━

모든 데이터는 실시간으로 계산한다.

저축 추가:
총 저축액 증가
→ 해당 범주 금액 증가
→ 연결된 목표 금액 증가
→ 목표 달성률 증가
→ 월별 캘린더 반영
→ 월별 통계 반영

소비 추가:
총 소비액 증가
→ 해당 범주 금액 증가
→ 월별 캘린더 반영
→ 소비 통계 반영

거래 삭제/수정 시에도 반대로 정확하게 계산한다.

페이지 새로고침 없이 UI가 즉시 업데이트되어야 한다.

━━━━━━━━━━━━━━━━━━
10. 디자인
━━━━━━━━━━━━━━━━━━

기존의 다크 그린 금융 대시보드 디자인을 유지한다.

저축/수입:

* Green

소비:

* Red

단, 소비의 빨간색은 너무 강한 네온 레드가 아니라 프리미엄 금융 앱에 어울리는 차분한 레드 계열을 사용한다.

전체 배경:
거의 검정에 가까운 다크

카드:
Dark charcoal

텍스트:
White / Light gray

저축:
Green accent

소비:
Red accent

그래프:
Green / Red

숫자를 가장 중요한 시각적 요소로 만든다.

━━━━━━━━━━━━━━━━━━
11. 모바일 UI
━━━━━━━━━━━━━━━━━━

스마트폰에서 사용하는 것을 최우선으로 한다.

특히:

* 금액 버튼을 손가락으로 누르기 편하게 한다.
* 버튼을 여러 번 빠르게 눌러도 정상적으로 누적된다.
* 캘린더가 모바일 화면에서 깨지지 않는다.
* 숫자가 잘리지 않는다.
* 탭 전환이 직관적이다.
* 가로 스크롤이 발생하지 않는다.
* 하단 네비게이션이 있다면 기존 구조를 유지하면서 자연스럽게 통합한다.

━━━━━━━━━━━━━━━━━━
12. 데이터 보존
━━━━━━━━━━━━━━━━━━

기존 Local Storage 데이터를 최대한 보존한다.

기존 저축 데이터가 있다면 새로운 범주/소비 시스템을 추가하면서 데이터가 삭제되지 않도록 한다.

데이터 구조가 변경된다면 migration 처리를 해서 기존 데이터를 새로운 구조에서도 사용할 수 있도록 한다.

━━━━━━━━━━━━━━━━━━
최종 목표
━━━━━━━━━━━━━━━━━━

이 앱을 단순한 저축 기록 앱이 아니라

“개인 자산의 유입·저축·소비를 한눈에 관리하는 개인 금융 대시보드”

형태로 완성한다.

특히 다음 5개가 반드시 정상 작동해야 한다.

1. 금액 버튼 여러 번 누르면 누적
2. 저축 / 소비 분리
3. 저축 / 소비 각각 사용자 지정 범주
4. 여러 개의 저축 목표 추가 및 수정
5. 월별 캘린더에서 날짜별 저축/수입과 소비를 색상과 숫자로 확인

수정 완료 후 실제로 각 기능을 테스트하고, 콘솔 에러가 없는지 확인한다.
